Topics Covered

The exercises in this folder cover the core C topics from the W3Schools curriculum:

Syntax & Output: Basic main() structure, printf(), and comments.

Variables & Data Types: Working with int, float, double, char, and format specifiers.

Operators: Arithmetic, assignment, comparison, and logical operators.

Control Flow: Conditional logic (if, else, switch) and loops (while, for).

Arrays & Strings: Handling arrays and basic string operations.

User Input & Memory: Using scanf(), memory addresses, and introductory pointers.

Functions: Creating and calling custom functions with parameters and return values.
